Getting started

  1. Download the Windows installer above.
  2. Run the setup file and follow the installation prompts.
  3. Launch Morning Market Scanner from your Start menu.
  4. Use Tools & Learning → Updates to check for new releases.

Windows may display a SmartScreen warning for an unsigned installer. Only run software from sources you trust. Market data is informational and not investment advice.
